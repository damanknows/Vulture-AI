Implementation

How to build this for production

1

Scanning engine

Python with socket + python-nmap, or pure Java NIO. Performs TCP connect scans, banner grabbing for version detection, optional SYN scans via libpcap.

python scanner.py --target 192.168.1.0/24 \
  --profile full --cve --json out.json
2

Vulnerability matching

Query the NVD CVE 2.0 API for CPE matches, cache results locally in SQLite, score by CVSS v3.1, flag KEV (Known Exploited Vulnerabilities).

GET https://services.nvd.nist.gov/rest/json/cves/2.0
  ?cpeName=cpe:2.3:a:apache:http_server:2.4.49
3

Spring Boot backend

REST API exposes /api/scans, /api/hosts, /api/cves. Persists scans to PostgreSQL, runs scans asynchronously via @Async jobs.

@RestController
class ScanController(svc: ScanService) {
  @PostMapping("/api/scans")
  fun create(@RequestBody req: ScanRequest) =
    svc.start(req)
}
4

Chat with your scan (RAG)

LangChain + FAISS or ChromaDB: load scan JSON, chunk, embed, retrieve top-k for each question, send to LLM with the chunk as context. Small scans fit directly in the context window.

from langchain.chains import RetrievalQA
qa = RetrievalQA.from_chain_type(
  llm=ChatOpenAI(model="gpt-4o-mini"),
  retriever=vectorstore.as_retriever(k=8))
qa.run("Any exploitable database CVEs?")
5

Dashboard frontend

React + Recharts (or vanilla JS + Chart.js as in this demo). Polls /api/scans/:id while a scan runs, renders severity KPIs, host table, CVE feed, chat panel.

6

Containerise

Docker Compose: scanner, backend, frontend, postgres, redis. Front this with Nginx + a Let's Encrypt certificate.

docker compose up -d scanner backend frontend
